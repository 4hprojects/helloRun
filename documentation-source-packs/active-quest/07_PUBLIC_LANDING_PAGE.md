# Phase 6: Permanent Active Quest Landing and Archives

## Routes (proposed, check existing first)
`/active-quest` permanent overview, `/active-quest/<year>` annual archive, `/events/<month>-active-quest-<year>` existing monthly route; avoid changing legacy slugs.

## Page hierarchy
1. Hero: Active Quest, `Your Distance. Your Pace. Your Quest.` and free monthly virtual distance challenge.
2. Current or next edition tile with date/status/category and clear registration CTA.
3. Six category explanation cards.
4. How to participate and proof validation summary (clearly distinguish available sync vs Coming Soon).
5. Digital badge/certificate descriptions only when configured.
6. Results/finishers with privacy preferences.
7. Past event archive, including accurately named historical editions if linked by admin.
8. FAQ and next month navigation.

## SEO and accessibility
One canonical series URL, individual canonical monthly event pages, unique dynamic information, descriptive metadata, JSON-LD only if matching actual public event details, mobile-first, alt text, readable labels, accessible progress indications. Avoid SEO promises based solely on duplicative monthly copy.

## Integrity
No future event is represented as accepting registrations when unpublished. Archive does not rename May–August Active Quest or September–October Active Run events. Respect opt-outs when showing participants.

## Acceptance
Responsive, keyboard accessible, correct active-month selection in PHT, valid canonical URLs, past events visible, missing edition produces helpful fallback.
