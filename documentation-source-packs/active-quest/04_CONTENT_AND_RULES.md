# Phase 3: Reusable Content, Eligibility and Rules

## Content model
Store versioned reusable editorial blocks separate from dynamic fields. Prefer structured rendering to copied HTML. Admin may preview exactly what participant sees, including dates and six categories.

## Canonical public headings
About the Challenge; Choose Your Quest; How to Join; Eligible Activities; How Proof Works; Valid Activity Rules; Leaderboard and Privacy; Digital Rewards; Dates and Deadlines; FAQ.

## Canonical participant rules
1. Register for one of six categories within the registration window, free of charge.
2. Complete eligible running, walking, jogging, hiking, trail running or documented treadmill activity during the month. One qualifying activity must have at least 1 km.
3. Submit eligible proof before deadline. Approved activities alone count toward progress.
4. The same real activity cannot count twice inside the same monthly edition. Cross-event reuse is governed by each event's rules; unique lifetime-distance aggregation deduplicates underlying activities.
5. Screenshot tab requires an activity screenshot. Optional URL may be verified where accessible; an inaccessible URL is marked unverified, not rejected for that reason alone. Enabled provider sync may replace screenshot only through a supported authenticated integration.
6. Resolve conflicting evidence before submission. Organizer review can flag, request correction, approve or reject evidence.
7. Finisher status requires approved total >= selected category target. Extra kilometers never silently change category.
8. Respect activity privacy and leaderboard visibility settings. Final decisions and exceptions are logged and subject to administrative appeal/correction policy.
9. No participant is automatically registered in later monthly editions.

## Rules requiring repository confirmation
Check existing category labels, treadmill evidence requirements, distance rounding, activity time/date timezone handling, submitted-on dates, tie-breaks, appeals, and definition of public name preferences. Do not silently change existing policies to match text.

## Editorial integrity checks
Compare structured dates/categories/reward availability with rendered copy; block contradictory text; allow only verifiable reward claims; show policy version and date modified when substantive changes occur.

## Acceptance
Content is accurate for a 28-, 29-, 30- and 31-day month; changing the configured 22nd deadline updates all dates in preview; published material policy changes are versioned.
