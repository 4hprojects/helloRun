# Documentation Source Packs

These files are unmodified source material supplied for planning and comparison.
They are not canonical HelloRun status, requirements, or backlog.

- `active-quest/`: 13 original Active Quest planning files.
- `hello-motion/`: 3 original Hello Motion planning files.

File contents and names remain byte-preserved. The packs live outside `docs/`
because one original heading sequence does not satisfy the repository's governed
Markdown quality gate.
