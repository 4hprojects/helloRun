## Content Rules

- Give each primary intent one canonical target.
- Use supporting language naturally where it improves the answer; never target density.
- Do not create doorway pages, location permutations, year permutations, or near-duplicate comparisons.
- Do not imply event availability, free participation, medals, certificates, accreditation, or commercial relationships without current evidence.
- Prefer internal links that move a reader from explanation to the appropriate guide, workflow, or event listing.
- Propose a new page only when Search Console shows a relevant unmet intent and no existing page can satisfy it without changing purpose.

## Search Console Review Checklist

- Export query and page performance for at least the most recent 90-day comparable period.
- Group queries by intent rather than exact spelling.
- Confirm whether the mapped target already receives impressions for that intent.
- Record cannibalization when two HelloRun pages receive the same primary-intent queries.
- Improve the stronger existing target before considering consolidation or a new page.
- Add a content gap only with the supporting query group, affected audience, existing-page limitation, and proposed success measure.
